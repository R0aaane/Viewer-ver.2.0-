## ここまでの判断

サムネイル初回生成には実測で遅延がある。一方、今回の少数同時取得中はAPI全体の応答停止が再現しない。大規模・継続負荷やSafari利用時と同条件の結果までは保証しない。

起動時のJS再取得と、読込済み画面のスクロール・サイドバーのかくつきは分けて扱う。上記からSafariのGPU負荷やCPU負荷を断定することはできない。
